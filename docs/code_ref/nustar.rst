======
NuSTAR
======

Helper tools for the Nuclear Spectroscopic Telescope ARray (NuSTAR) observatory spectral files.

.. note::

    NuSTAR data is downloaded using the `NuSTAR Catalog <https://heasarc.gsfc.nasa.gov/db-perl/W3Browse/w3table.pl?tablehead=name%3Dnumaster&Action=More+Options>`__ with the data pipeline being handled by `HEASoft <https://heasarc.gsfc.nasa.gov/docs/software/lheasoft/download.html>`__.
